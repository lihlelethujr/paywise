PayWise installable web app: files must stay together in ONE folder (no sub-folders).
index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png, icon-maskable-512.png, apple-touch-icon.png

Host on GitHub Pages from your phone:
1. Make a free account at github.com (use the browser, desktop site if needed).
2. Create a new PUBLIC repository named paywise.
3. Add file > Upload files, and upload all 7 files above. Commit.
4. Settings > Pages > Deploy from a branch > main > / (root) > Save.
5. After a minute your app is at https://YOURNAME.github.io/paywise/
6. Open that link on your phone:
   Android/Huawei: browser menu > Install app or Add to Home screen.
   iPhone: Safari > Share > Add to Home Screen.
